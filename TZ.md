# Техническое задание: Мобильное приложение «Who's Who»

## 1. Общие сведения

### 1.1 Назначение
Мобильное приложение для запоминания людей перед мероприятиями. Пользователь добавляет
людей с фотографиями и информацией, а приложение проводит тренировку в формате викторины.

### 1.2 Целевая платформа
- Android 8.1+ (API 27)
- Язык: Java
- Хранение: SQLite (только локально, без сервера)
- UI: Material Design

## 2. Функциональные требования

### 2.1 Управление мероприятиями (Events)
- Создание, редактирование, удаление мероприятий
- Поля: название (обязательное), дата (опционально), описание (опционально)
- Список мероприятий с отображением количества привязанных людей
- Сортировка по дате создания (новые сверху)

### 2.2 Управление людьми (Persons)
- Добавление, редактирование, удаление людей
- Привязка людей к мероприятиям (связь M:N)

#### Обязательные поля:
- Имя (first_name) — обязательное
- Фото (photo_path) — обязательное

#### Основные поля:
- Фамилия (last_name)
- Компания (company)
- Должность (position)
- Контекст знакомства (context) — до 200 символов
- Заметка (note)

#### Дополнительные поля (секция «Дополнительная информация»):
- Увлечения (hobbies)
- Интересы (interests)
- Семейный статус (family_status)
- Имя партнёра (partner_name)
- Имена детей (children_names)
- Имена домашних животных (pet_names)
- Вероисповедание (religion)
- Политические взгляды (political_views)

### 2.3 Фото
- Съёмка с камеры или выбор из галереи
- Автоматическое масштабирование до разумного размера
- Хранение в internal storage приложения
- Отображение круглых аватаров в списках

### 2.4 Тренировка (Quiz) — 5 режимов

#### Режим 1: Фото → Имя
- Показывается фото человека
- Выбор имени из 4 вариантов (кнопки)

#### Режим 2: Описание → Фото
- Показывается текстовое описание (должность + компания + контекст)
- Выбор фото из 4 вариантов (сетка 2×2)

#### Режим 3: Имя → Должность
- Показывается имя человека
- Выбор должности из 4 вариантов (кнопки)
- Доступен только для людей с заполненной должностью

#### Режим 4: Факт → Фото
- Показывается факт (увлечение или интерес)
- Выбор фото из 4 вариантов (сетка 2×2)
- Доступен только для людей с заполненными увлечениями/интересами

#### Режим 5: Компания → Фото
- Показывается название компании
- Выбор фото из 4 вариантов (сетка 2×2)
- Доступен только для людей с заполненной компанией

#### Правила тренировки:
- Минимум 5 людей в мероприятии для начала тренировки
- Максимум 20 вопросов за сессию (или меньше, если людей мало)
- Каждый вопрос: 1 правильный + 3 дистрактора
- Подсветка правильного (зелёный) и неправильного (красный) ответа
- Пауза 1.5 секунды после ответа перед следующим вопросом
- Прогресс-бар и счётчик вопросов

#### Адаптивный алгоритм:
- Формула веса: `weight = wrong_count / (correct_count + 1) + 0.5`
- Чем выше вес — тем чаще показывать
- Взвешенный случайный выбор для генерации вопросов

#### Экран результатов:
- Процент правильных ответов (крупно)
- Количество: "X правильных из Y"
- Список людей с ошибками
- Кнопка «Повторить все»
- Кнопка «Повторить ошибки» (только из людей с ошибками)
- Кнопка «Вернуться к мероприятию»

### 2.5 Экспорт / Импорт
- Экспорт всех данных (люди + мероприятия + привязки) в JSON файл
- Фотографии встраиваются как Base64
- Импорт из JSON файла с заменой всех существующих данных
- Сохранение в `/sdcard/WhosWho/` или internal storage
- Переназначение ID при импорте (oldId → newId маппинг)

### 2.6 Экран настроек
- Кнопка экспорта данных
- Кнопка импорта данных (выбор из найденных .json файлов)
- Доступ через иконку настроек на экране списка мероприятий

## 3. Экраны приложения

### 3.1 Splash-экран
- Логотип приложения
- Название «Who's Who»
- Подзаголовок «Remember every face»
- Автопереход через 1.5 секунды

### 3.2 Список мероприятий
- Заголовок «Events»
- Список карточек (название, дата, количество людей)
- FAB (+) для создания нового
- Иконка настроек (шестерёнка) в заголовке
- Удаление длинным нажатием
- Пустое состояние: иконка + текст «No events yet»

### 3.3 Экран мероприятия
- Заголовок события (название, дата, описание)
- Список людей (аватар + имя + компания)
- Нажатие на человека → редактирование
- Длинное нажатие → удаление из мероприятия
- Кнопка «Добавить человека» → диалог (создать нового / выбрать существующего)
- Кнопка «Начать тренировку» (неактивна при < 5 людей)

### 3.4 Редактор человека
- Фото (нажатие для выбора камера/галерея)
- Все текстовые поля
- Секция «Дополнительная информация» (развёрнута по умолчанию)
- Кнопка «Сохранить»

### 3.5 Экран викторины
- Прогресс-бар сверху
- Счётчик вопросов «X / Y»
- Зона вопроса (фото или текст)
- Зона ответов (4 кнопки или сетка 2×2 фото)

### 3.6 Экран результатов
- Процент (крупный шрифт)
- Счёт «X правильных из Y»
- Список ошибок (если есть)
- 3 кнопки действий

### 3.7 Настройки
- Секция «Экспорт данных» с кнопкой
- Секция «Импорт данных» с кнопкой

## 4. Нефункциональные требования

- Все данные хранятся только локально (без сервера)
- Фото масштабируются для экономии памяти
- LruCache для кэширования битмапов
- Foreign keys ON в SQLite с каскадным удалением
- Одноручное управление (кнопки внизу экрана)
